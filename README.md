# devhub

ZENAIM KEYBOARD と LAMZU Maya X を、ひとつの軽いアプリで設定します。

- 公式アプリ 2 つ（ZENAIM SOFTWARE / LAMZU Web ドライバ）の置き換え
- 本体 約 2MB、常駐時のメモリ 約 7MB（画面は Edge のアプリウィンドウで開く）
- ローカル API があるので、Claude などから設定を変更できる

## 対応機種

| 機種 | 状態 |
|---|---|
| ZENAIM KEYBOARD ZK1 60JIS | 読み書き確認済み |
| ZK1 60US / 80JIS / 80US | 定義のみ（未確認） |
| LAMZU Maya X（8K ドングル） | 読み書き確認済み（プロファイル 1〜3） |
| LAMZU Maya X（1K ドングル / 有線） | 定義のみ（未確認） |

## できること

**キーボード**
- キーごとの ON / OFF 位置（0.01mm 単位）
- ラピッドトリガー（押し込み・戻り感度、範囲、ビヨンドモード）
- キー割り当て（通常 / Fn レイヤー）
- SOCD（同時押しの優先）
- チャタリング対策（判定の保持時間）
- 押し込み量のライブ表示（誤入力の原因調査に）
- プロファイル切り替え（ベース / 一時 / MEM1〜3）

**マウス**
- DPI 段階（X/Y 別設定可）・ポーリングレート（〜8000Hz）・LOD
- デバウンス（クリックのチャタリング対策）
- モーションシンク・競技モード・リップルコントロール・角度スナップ・角度補正
- スリープ時間・プロファイル切り替え

**共通**
- プリセット（キーボード + マウスをまとめて保存 / 適用）
- Windows 起動時の自動起動

## 使い方

`devhub.exe` を実行するとウィンドウが開きます。2 回目以降はウィンドウだけ開きます。

公式アプリと同時に起動すると通信がぶつかることがあるので、どちらか片方だけ使ってください。

## Claude から操作

[docs/API.md](docs/API.md) を参照。例:

```
A と D をラピッドトリガー 0.15mm にして
```

と頼めば、Claude が `PATCH /api/keyboard` を送ります。

## ビルド

```
cd ui
npm install
npx vite build
cd ..
cargo build --release
```

## 注意

- 非公式ソフトです。プロトコルは公式ソフトの解析によるもので、メーカーとは無関係です
- 設定はデバイス本体に書き込まれます。不安なら先にプリセットで保存してください
- ファームウェア更新機能はありません（公式ツールを使ってください）
